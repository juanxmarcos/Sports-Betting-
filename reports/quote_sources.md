### Findings and links

- **The Odds API (the-odds-api.com), in use** (verified): Terms last updated 31 August 2026. Cost is markets x regions; /sports and /events are free. <https://the-odds-api.com/liveapi/guides/v4/> <https://the-odds-api.com/terms-and-conditions.html>
- **The Odds API: `bookmakers` parameter (same key, same quota)** (owner_opt_in): Guide: "Every group of 10 bookmakers is the equivalent of 1 region"; `bookmakers` takes priority over `regions`. The bookmaker list marks some keys "paid subscriptions only" (for example Caesars, Fanatics). Whether the free plan returns every other key is unconfirmed until probed. <https://the-odds-api.com/liveapi/guides/v4/> <https://the-odds-api.com/sports-odds-data/bookmaker-apis.html>
- **The Odds API: `us_ex` keys (Polymarket, Kalshi, Novig, ProphetX)** (blocked): These are contract prices, not sportsbook odds: settlement rules, fees, currency and access differ. The connector refuses these keys and drops them if returned. Using them needs its own design (separate table, market-definition checks) and its own PR. <https://the-odds-api.com/sports-odds-data/bookmaker-apis.html>
- **Betting Data API (theoddsapi.com, now redirects to bettingdataapi.com)** (owner_opt_in): A different company from The Odds API: "operated by TheOddsAPI LLC, a Wyoming limited liability company". The free tier is described as "Evaluate with production data", moneyline only, no card. Not proven permanently free or cleared for storage, so no adapter is built. <https://bettingdataapi.com/pricing> <https://bettingdataapi.com/terms>
- **Polymarket Gamma API (public, keyless)** (blocked): Documented public API; limit 500 requests per 10 s on /events. Terms effective 11 August 2026 also bar trading from restricted jurisdictions. Prices are 0 to 1 per share in USDC with a bid/ask spread and per-market fees (`feesEnabled`); soccer is three separate Yes/No contracts. No adapter and nothing stored until the owner confirms the data rights. <https://docs.polymarket.com/quickstart/introduction/rate-limits> <https://polymarket.com/tos> <https://github.com/Polymarket/agent-skills/blob/main/market-data.md>
- **Kalshi public market-data endpoints** (blocked): Docs: "several public endpoints that don't require API keys"; data "can lag the exchange by several seconds". Data terms were not found on the docs page, so nothing is used. <https://docs.kalshi.com/getting_started/quick_start_market_data>
- **Betfair Exchange API (own key)** (paid): "In all cases, a personal or corporate KYC-verified Betfair account is required". Operators and companies wanting Exchange data are sent to data sales. The page does not mention the Delayed App Key. No account is opened. <https://support.developer.betfair.com/hc/en-us/articles/360002464152-Which-API-Licence-Do-I-Require>
- **Pinnacle API (direct)** (paid): Access is by application, decided per use case. Not applied for. <https://www.pinnacle.com/en/api/>
- **Smarkets API (direct)** (unavailable): docs.smarkets.com returned only a page title to an automated read; access rules and data terms could not be read. <https://docs.smarkets.com/>
