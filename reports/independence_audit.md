# Bookmaker independence audit (2026-11-13 12:17 UTC)

Generated by `python -m sbi independence` from the stored database (read-only). Developer report; see docs/METHODOLOGY.md, section *Bookmaker independence*.

**Deployed rule: indep-v1 (`legacy`).** Rule v2 is **staged**: it is computed for every candidate and reported here, but it does not decide what is published.

- **Rule v1 (legacy):** a bookmaker missing from the ownership map counts as its own operator.
- **Rule v2 (verified):** only operators verified in `sbi/sources/books.py` count toward the 3-bookmaker gate, the leave-one-out reference uses only them (one vote per operator), and every v1 check must still pass. It can block a v1 pick and can never add one.
- Unverified bookmakers stay in monitoring, the watchlist and the best-price search under both rules.
